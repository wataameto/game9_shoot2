# NEON STARFIGHTER 3D - Development Rules

## Commands
- **Run dev server**: `npm run dev` (Runs Vite on http://localhost:5175/)
- **Build project**: `npm run build` (Outputs to `dist/`)
- **Run tests**: `npx playwright test`

## Project Rules & Guidelines
- **File Management**: Do NOT delete unused or temporary files directly. Always move them to the `.trash/` directory at the project root without asking the user.
- **Browser Compatibility**: Keep client-side interactions premium but lightweight.
